# 📊 Intermediate Pandas

This folder contains intermediate-level Pandas examples to improve data manipulation and analysis skills.

## 📂 Files

- **Filtering-of-rows.py** – Filter rows using conditions.
- **Filtering-of-columns.py** – Select and filter specific columns.
- **Shape-method.py** – Get the shape (rows and columns) of a DataFrame.

## 🎯 Topics Covered

- Row Filtering
- Column Filtering
- DataFrame Shape
